# rendrilo 要件一覧

## 1. 文書情報

- 文書種別: 初期要件定義
- 対象リリース: MVP（v0.1）
- ステータス: Draft
- 最終更新日: 2026-09-13

## 2. プロダクト概要

rendrilo は、画像をサーバーへアップロードせず、ブラウザ内で別形式へ変換できるWebアプリケーションである。インストールやアカウント登録を不要とし、単一画像と複数画像のどちらも短い操作で変換できることを目指す。

「Universal」は無制限な形式対応を意味するものではなく、対応形式を段階的に拡張できる変換基盤と、一貫した操作体験を表す。

## 3. 前提

初期資料がプロダクト名と「Universal Image Converter」のみであるため、MVPでは次を前提とする。

- 提供形態はレスポンシブWebアプリケーションとする
- 変換処理は原則として利用者のブラウザ内で完結させる
- アカウント、クラウド保存、課金、サーバー側変換は対象外とする
- UIの初期言語は英語とし、日本語を追加できる構造にする
- デスクトップ版・CLI版は、変換コアを再利用できる将来候補とする

前提を変更する場合は、本書と実装プランを同時に更新する。

## 4. 対象ユーザーと利用場面

### 4.1 対象ユーザー

- ファイル形式を手早く変えたい一般ユーザー
- Web掲載用に画像の容量や寸法を調整したい制作者・開発者
- 外部サービスへ画像をアップロードしたくないユーザー

### 4.2 主要ユースケース

1. 画像をドラッグ＆ドロップし、出力形式を選んで変換する
2. 複数画像へ共通設定を適用し、一括変換する
3. 幅・高さ・品質を調整してファイル容量を抑える
4. 変換結果を個別、またはZIPにまとめて保存する

## 5. スコープ

### 5.1 MVPに含むもの

- JPEG、PNG、WebPの読み込みと相互変換
- AVIFの読み込み・出力（実行環境が対応する場合）
- 単一・複数ファイルの選択とドラッグ＆ドロップ
- 出力形式、品質、画像寸法の設定
- アスペクト比を維持したリサイズ
- EXIF Orientationを反映した正しい向きでの出力
- 変換前後のファイルサイズ・寸法・形式の表示
- 個別ダウンロードとZIP一括ダウンロード
- 変換の進捗、成功、警告、失敗理由の表示
- 処理のキャンセル、対象画像の削除、全件クリア
- キーボード操作とスクリーンリーダーに配慮した基本操作

### 5.2 MVPに含まないもの

- ユーザー登録、ログイン、履歴のクラウド同期
- サーバーへの画像アップロード、サーバー側変換
- 画像編集（切り抜き、描画、フィルター、背景除去）
- 動画、音声、PDF、RAW画像の変換
- アニメーションを維持したGIF・WebP変換
- OCR、生成AI、メタデータ編集
- ネイティブデスクトップアプリ、モバイルアプリ、CLI

### 5.3 将来候補

- GIF、HEIC/HEIF、TIFF、BMP、ICO、SVGなどの入力対応
- アニメーション画像の変換
- プリセットと設定の端末内保存
- PWAによるオフライン利用
- デスクトップ版・CLI版

## 6. 機能要件

優先度は `Must`（MVP必須）、`Should`（MVPで可能な限り対応）、`Could`（将来候補）で示す。

### 6.1 ファイル入力

| ID       | 要件                                                             | 優先度 |
| -------- | ---------------------------------------------------------------- | ------ |
| FR-IN-01 | 利用者はファイル選択ダイアログから1件以上の画像を選択できる      | Must   |
| FR-IN-02 | 利用者は画像を画面へドラッグ＆ドロップして追加できる             | Must   |
| FR-IN-03 | JPEG、PNG、WebPを入力できる                                      | Must   |
| FR-IN-04 | 実行環境が対応する場合はAVIFを入力できる                         | Must   |
| FR-IN-05 | 拡張子だけでなく実データを検査し、未対応・破損ファイルを拒否する | Must   |
| FR-IN-06 | 同名ファイルを含む複数画像を安全に扱える                         | Must   |
| FR-IN-07 | 追加前に対応形式と利用上限を確認できる                           | Should |

### 6.2 変換設定

| ID        | 要件                                               | 優先度 |
| --------- | -------------------------------------------------- | ------ |
| FR-SET-01 | JPEG、PNG、WebPから出力形式を選択できる            | Must   |
| FR-SET-02 | 実行環境が対応する場合はAVIFを出力形式に選択できる | Must   |
| FR-SET-03 | 非可逆形式では品質を1〜100の範囲で設定できる       | Must   |
| FR-SET-04 | 出力する幅または高さをピクセル単位で指定できる     | Must   |
| FR-SET-05 | アスペクト比の維持を切り替えられる                 | Must   |
| FR-SET-06 | 拡大を許可するか選択でき、初期値では拡大しない     | Should |
| FR-SET-07 | 透過を持たない形式へ変換する際の背景色を選択できる | Must   |
| FR-SET-08 | 全画像へ共通設定を適用できる                       | Must   |
| FR-SET-09 | 画像ごとに設定を上書きできる                       | Could  |

### 6.3 変換処理

| ID        | 要件                                                                     | 優先度 |
| --------- | ------------------------------------------------------------------------ | ------ |
| FR-CNV-01 | 画像データを外部サーバーへ送信せずブラウザ内で変換する                   | Must   |
| FR-CNV-02 | EXIF Orientationを反映して意図した向きで出力する                         | Must   |
| FR-CNV-03 | 元ファイルを変更しない                                                   | Must   |
| FR-CNV-04 | 複数画像を順次または並列で処理し、画像ごとの状態を表示する               | Must   |
| FR-CNV-05 | 利用者は実行中の処理をキャンセルできる                                   | Must   |
| FR-CNV-06 | 1件の失敗で、処理可能な他の画像まで中断しない                            | Must   |
| FR-CNV-07 | メイン画面の操作を妨げないよう、重い処理をバックグラウンドスレッドで行う | Should |
| FR-CNV-08 | 不要になった画像データと一時URLを速やかに解放する                        | Must   |

### 6.4 結果とダウンロード

| ID        | 要件                                                    | 優先度 |
| --------- | ------------------------------------------------------- | ------ |
| FR-OUT-01 | 変換結果を画像ごとにプレビューできる                    | Must   |
| FR-OUT-02 | 変換前後の形式、寸法、ファイルサイズを確認できる        | Must   |
| FR-OUT-03 | 変換結果を画像ごとにダウンロードできる                  | Must   |
| FR-OUT-04 | 複数の変換結果をZIPファイルとして一括ダウンロードできる | Must   |
| FR-OUT-05 | 元のベース名を維持し、出力形式に合う拡張子を付ける      | Must   |
| FR-OUT-06 | ファイル名が衝突する場合は連番を付けて上書きを防ぐ      | Must   |

## 7. 非機能要件

### 7.1 プライバシーとセキュリティ

| ID         | 要件                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| NFR-SEC-01 | 画像本体、ファイル名、変換結果を外部へ送信しない                               |
| NFR-SEC-02 | アクセス解析を導入する場合、画像やファイル名をイベントへ含めない               |
| NFR-SEC-03 | ファイル形式・サイズ・画素数を検証し、過大なメモリ消費を抑制する               |
| NFR-SEC-04 | 外部リソースを参照する入力形式は、安全な無効化またはサニタイズなしに処理しない |
| NFR-SEC-05 | 依存パッケージを固定し、継続的に脆弱性を確認する                               |

### 7.2 性能と安定性

| ID          | 要件                                                                         |
| ----------- | ---------------------------------------------------------------------------- |
| NFR-PERF-01 | 20MPのJPEG 1枚を、標準的なデスクトップ環境で操作不能にせず処理できる         |
| NFR-PERF-02 | MVPの初期上限を1ファイル100MB、合計500MB、100ファイルとし、処理前に検証する  |
| NFR-PERF-03 | 端末性能やメモリ不足により安全な処理が難しい場合、処理を止めて理由を表示する |
| NFR-PERF-04 | 変換キューの同時実行数を制御し、端末のフリーズを防ぐ                         |
| NFR-REL-01  | 失敗した処理を、他の変換結果を失わずに再実行できる                           |

数値目標は試作時の計測結果をもとに見直す。

### 7.3 対応環境

| ID          | 要件                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| NFR-COMP-01 | リリース時点のChrome、Edge、Firefox、Safariの最新2メジャーバージョンを対象とする |
| NFR-COMP-02 | 幅320px以上の画面で主要操作を完了できる                                          |
| NFR-COMP-03 | 形式ごとの実行時対応状況を機能検出し、未対応機能へ安全にフォールバックする       |

### 7.4 アクセシビリティと品質

| ID          | 要件                                                     |
| ----------- | -------------------------------------------------------- |
| NFR-A11Y-01 | WCAG 2.2 AAを目標とする                                  |
| NFR-A11Y-02 | 主要操作をキーボードのみで実行できる                     |
| NFR-A11Y-03 | 状態変化を色だけに依存せず、テキストと支援技術へ通知する |
| NFR-QLT-01  | 変換コア、状態管理、ファイル名生成に自動テストを設ける   |
| NFR-QLT-02  | 主要ユーザーフローをブラウザ統合テストで検証する         |

## 8. データとプライバシー

- 画像本体と変換結果はメモリ上でのみ扱い、永続化しない
- 画面から削除した画像と、タブを閉じた際のデータは復元できない
- 設定を端末へ保存する場合は、画像とファイル名を含めず、利用者が消去できるようにする
- 外部通信が発生する機能は、画像変換の必須経路から分離する

## 9. MVP受け入れ条件

1. JPEG、PNG、WebPの各サンプルを読み込み、指定した主要形式へ変換して保存できる
2. 10枚以上の画像を共通設定で一括変換し、ZIPで保存できる
3. 縦横比を維持したリサイズ、品質変更、透過背景の合成が正しく動作する
4. 壊れた画像、未対応形式、上限超過を安全に拒否し、対処方法を表示する
5. 変換処理中もキャンセル操作を受け付け、画面が長時間応答不能にならない
6. 開発者ツールで確認した際、画像本体・ファイル名を外部へ送る通信がない
7. 対象ブラウザの主要フローについて自動テストまたは手動確認が完了している
8. キーボードのみで追加、設定、変換、ダウンロード、クリアを実行できる
9. CI上で型検査、静的解析、単体テスト、ビルドが成功する

- UIの初期言語を英語とするか、日本語とするか
- MVPでAVIFを必須対応にするブラウザ範囲
- ファイル数・サイズ・画素数上限の妥当性
- 変換結果でICCカラープロファイルやその他メタデータを保持する範囲
- アクセス解析とエラー収集を導入するか
- 公開先と独自ドメインの有無
